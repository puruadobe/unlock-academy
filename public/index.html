What do we need to play together?

For a local demo: one running Node.js 22+ app server and two independent browser tabs. No database or AI key is needed to play an existing room.

For separate devices: everyone must reach the same host address. Use the same Wi-Fi with a configured shared address, or a single HTTPS-hosted Node server for remote players. A static website alone is not enough.

For persistent games: this prototype keeps sessions in server memory, so restarting loses them. Shared storage and recovery are prerequisites for durable sessions or multiple servers.

See MULTIPLAYER.md in the source repository for setup commands, network requirements, and public-hosting limitations.

Host a mission

2–8 players. Share the join code, then start when everyone is ready. You can host a room from your local collection.
